# Shmal El-Hejaz — Static Web UI (SHMAL-ELHEJAZ)

A static frontend web project containing custom CSS stylesheets (INDEX.CSS, CARD CSS) and JavaScript (JAVA SCRIPT) for the Shmal El-Hejaz interface.

## Project Structure
``text
├── INDEX.CSS         # Main layout & page styles
├── CARD CSS          # Card component styles
└── JAVA SCRIPT       # Client-side interactivity
``
